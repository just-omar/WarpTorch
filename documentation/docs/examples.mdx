# Usage Examples 💻

## Try WarpTorch in Jupyter Lab 🧪

The best way to explore WarpTorch is through our interactive Jupyter Lab environment!

### Option 1: Docker (Easiest) 🐳

<BrowserWindow>

```bash
# Clone the repository
git clone https://github.com/just-omar/WarpTorch.git
cd WarpTorch

# Start all services with one command
make up

# Jupyter Lab will be available at:
# http://localhost:8888
# Password: warptorch
```

</BrowserWindow>

**Features:**
- 🚀 One-command startup for all services
- 🎨 Pre-configured environment with all dependencies
- 📊 Access to example notebooks in `jupyter_notebooks/`
- 🔬 GPU auto-detection and acceleration
- 🌐 Plus web interface at `http://localhost:3005`

### Option 2: Manual Setup 💻

<BrowserWindow>

```bash
# Clone the repository
git clone https://github.com/just-omar/WarpTorch.git
cd WarpTorch

# Create virtual environment
python -m venv venv
source venv/bin/activate       # Linux/macOS
# venv\Scripts\activate         # Windows

# Install dependencies
pip install torch
pip install -r requirements.txt

# Start Jupyter Lab
jupyter lab
```

</BrowserWindow>

**Features:**
- 🔧 Full control over environment
- 🎯 Ideal for development and debugging
- 📚 Direct access to all project files
- ⚡ Same functionality as Docker version

## Example 1: Your first warp bubble

<BrowserWindow>

```python title="first_warp.py"
from core.metrics.alcubierre import get_alcubierre_metric
from core.solver.energy import get_energy_tensor
from core.visualizer import plot_3d

# Create a warp bubble moving at 1.5x speed of light
metric = get_alcubierre_metric(
    grid_size=(1, 64, 64, 64),  # grid size
    v=1.5,                      # velocity (1.5c)
    R=6.0,                      # bubble radius
    sigma=2.0,                  # wall thickness
    device="cuda"               # GPU acceleration
)

# Calculate how much energy is needed
energy = get_energy_tensor(metric)

# Visualize in 3D
plot_3d(metric)
```

</BrowserWindow>

**Result:** In 5 seconds you'll see a beautiful 3D visualization of a warp bubble!

## Example 2: Explore different metrics

<BrowserWindow>

```python title="compare_metrics.py"
from core.metrics.alcubierre import get_alcubierre_metric
from core.metrics.lentz import get_lentz_metric
from core.solver.energy import get_energy_tensor

# Alcubierre - classic warp (needs negative energy)
alcubierre = get_alcubierre_metric(v=2.0)
alcubierre_energy = get_energy_tensor(alcubierre)

# Lentz - modern metric (positive energy!)
lentz = get_lentz_metric(v=2.0)
lentz_energy = get_energy_tensor(lentz)

# Compare - how much energy is needed?
print(f"Alcubierre: {alcubierre_energy.min():.2f} (negative!)")
print(f"Lentz: {lentz_energy.min():.2f} (positive = more realistic)")
```

</BrowserWindow>

**Result:** Compare different warp metrics and understand which is more realistic!
